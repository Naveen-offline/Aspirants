# 📂 Java Array Problems Showcase

Welcome to my repository dedicated to solving **Array-based problems and real-world simulations using Java**. This collection features foundational exercises, mathematical operations on array elements, tracking algorithms, and interactive console-based simulations.

---

## 🛠️ Tech Stack & Tools

* **Language:** Java (JDK 8 or higher)
* **Core Concepts:** 1D Arrays, Linear Traversal, Interactive Loops (`while(true)`), Counter Arrays, Mathematical Functions (`Math.sqrt`, `Math.pow`).
* **Environment:** Built and managed utilizing GitHub Codespaces / VS Code.

---

## 📂 Repository Structure

The repository organizes structural implementations and data manipulation workflows into explicit problem sets:

```text
├── Applications/
│   ├── Bank.java             # Mimics deposits/withdrawals tracking via a transaction array
│   ├── Bus_Booking_1.java    # Iterative/sequential seat reservation tracker
│   ├── Bus_Booking_2.java    # Interactive targeted seat booking with collision detection
│   └── Movie_Rating.java     # Aggregates system metrics (Averages & frequency filters)
├── Mathematics/
│   ├── Find_Cube.java        # Calculates cubes using exponents
│   └── Find_SQRT.java        # Finds element-wise square roots
└── Logic_And_Filtering/
    ├── Count_num.java        # Divisibility-based element classifier
    ├── Duplicate_Element.java # Identifies recurrent entries via nested scanning
    ├── Non_Duplicate.java    # Isolates distinct items using state arrays
    └── Middle_element.java   # Computes array bounds to extract medians
